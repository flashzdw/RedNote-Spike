# 无畏契约爆能器爆炸范围计算器 — 实施计划

## 1. 概述（Summary）

交付一个**自包含的单文件 HTML**（`/workspace/index.html`），用于测算《无畏契约》中爆能器（Spike）安装后爆炸的**半径 35 米**范围。

核心能力：
1. 从 **13 张官方标准地图**中选择一张。
2. 展示该地图的**自绘矢量俯视示意图**，并高亮**可下包区域（下包区域）**。
3. 用户在可下包区域中选择一个安装点。
4. 点击「模拟爆炸」按钮，播放爆能器充能→引爆的加速动画。
5. 以安装点为圆心，显示半径 **35 米**的最终爆炸范围，并展示官方数据。

UI 采用无畏契约官方品牌风格（深色 + FF4655 红 + 切角硬朗边角 + 粗黑体）。

## 5. 架构与文件结构

单文件 `index.html`，内嵌全部 CSS / JS / SVG，**零外部依赖**：

```
/workspace/index.html
 ├ <head> 内联 CSS
 │   ├ 主题变量（配色 / 切角 clip-path / 字体）
 │   ├ 按钮 / 卡片 / 面板 / 徽章样式
 │   ├ 地图 SVG 与爆炸范围叠加层样式
 │   └ 动画关键帧（脉冲 / 扩张 / 白圈收缩 / 闪烁）
 ├ <body>
 │   ├ 头部：标题 + 副标题
 │   ├ 地图选择器（横排 chips / 下拉）
 │   ├ 主画布区：<svg>（示意图 + 下包区域 + 爆炸范围）
 │   ├ 信息面板：官方数据卡片（35m / 999 / 45s / 4s / 7s）
 │   └ 控制区：「模拟爆炸」「重置」按钮
 └ <script> 内联 JS
     ├ MAPS 数据模型（13 张元数据 + 坐标 + 下包多边形）
     ├ 渲染（地图选择 / SVG 绘制 / 状态重绘）
     ├ 交互（点选安装点 / 边界校验）
     └ 动画（充能倒计时 → 引爆扩张 → 定位 35m 范围）
```

## 6. 数据模型

在 JS 中定义 `MAPS` 数组，每项结构：

```js
{
  id: "ascent",
  nameZh: "亚海悬城", nameEn: "Ascent",
  location: "威尼斯，意大利",
  sites: ["A", "B"],                      // 含 C 的地图：["A","B","C"]
  world: { w: 130, h: 100 },              // 示意图外接尺寸（单位：米，近似官方尺度）
  plantZones: [                           // 可下包区域（米坐标，近似）
    { site: "A", path: [[xM,yM], ...] },
    { site: "B", path: [[xM,yM], ...] },
  ],
  defaultPlant: { "A": [xM,yM], "B": [xM,yM] },  // 各站点默认安装点（可选）
}
```

**坐标约定**：SVG 使用**逻辑「米」坐标系**；全局常量 `PX_PER_M = 6`（1 米 = 6 像素，视画布尺寸可调）。由此：
- 绘制示意图时，地图外接尺寸 `world.w / world.h`（米）直接映射到 SVG viewBox。
- `35m 半径` → 半径 35 × `PX_PER_M` 像素，保证数值与显示一致。
- 界面显示**比例尺**，并标注「示意图，空间比例近似」。

## 7. 渲染与交互

1. **地图选择**：横排切角 chips（或下拉）。切换后清空安装点与爆炸范围并重绘。
2. **俯视示意图**：每张图手绘 SVG（可辨识的三路/双路结构、A/B/C 站点位置、主要通道），配色贴近官方小地图（深底 + 亮线条 + 站点色块）。
3. **下包区域**：岚蓝半透明多边形 + 描边，右上角/角标标注「下包区域（示意）」，hover 高亮。
4. **点选安装点**：
   - 用户点击 `plantZones` 内任意点 → 放置三角 spike 图标（SVG 自绘）。
   - 点击区域外 → 提示「请在下包区域内选择安装点」。
   - 支持在一个区域内重新点选以移动安装点。
5. **模拟爆炸动画**（`requestAnimationFrame`，加速模拟，非真实 45 秒）：
   1. 「安装中（4s）」快速过渡；
   2. 充能倒计时加速播放，剩余时间越少 beep 越密集（视觉脉冲频率加快）；
   3. 最后 7 秒出现「逐渐收缩白圈」提示；
   4. 引爆：黑色圆自中心**扩张至 35m**，闪现「999 伤害 / 瞬间消灭」；
   5. 定格最终爆炸范围圈。
6. **最终展示**：35m 半径圆（红/黑描边 + 半透明填充）+ 半径标注「半径 35m · 999 伤害」+ 比例尺 + 官方数据卡片。
7. **重置按钮**：清除安装点与爆炸范围，回到未安装状态。

## 8. UI 风格（无畏契约官方风）

- **配色**：背景近黑 `#0F1923`；主红 `#FF4655`；辅助白 `#ECE8E1`；点缀青 `#00C5E5`；半透明深玻璃面板。
- **字体**：不引入外部字体；英文标题用系统粗黑（近似 DIN/Tungsten，`font-weight: 900` + `letter-spacing`），中文用系统黑体。
- **形状**：按钮/卡片采用 `clip-path: polygon(...)` 切角；细边框 + 红/青发光；斜切标题条。
- **背景**：深色 + 细网格线 + 轻微噪点/纹理（CSS 渐变实现，无外部图片）。
- **图标**：内联 SVG 自绘（三角 spike、V 字、站点字母徽章 A/B/C）。

## 9. 假设与决策

- 覆盖**全部 13 张标准地图**（用户已确认）。
- 地图俯视图采用**自绘矢量俯视示意图**（用户已确认），非官方截图；布局按官方俯视/小地图近似还原。
- 下包区域采用**近似勾画的多边形**并标注「示意」（用户已确认）；官方无公开精确坐标数据。
- 爆炸范围按官方 **35m 半径正圆**渲染（含 999 伤害/即死标注）；另加说明文字「游戏中该范围受墙体/掩体遮挡，此处为正圆形示意」。
- 比例：示意图以「米」为逻辑坐标、统一像素比例，空间比例为近似值；**准确口径以 35m 数值为准**。
- 爆炸动画为**加速模拟**，不等待真实 45 秒。
- 界面语言为**简体中文**。
- 不使用任何 AI 生成的图片作为地图（避免虚构布局）；所有视觉均为矢量/CSS 自绘。
